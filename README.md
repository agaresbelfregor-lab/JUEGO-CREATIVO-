# 🎮 JUEGO-CREATIVO

Es un juego sencillo pero divertido para enseñar a los niños y evaluar su memoria auditiva.

## 🚀 Cómo ejecutar el proyecto
1. Descarga o clona este repositorio.
2. Abre el archivo `índice.html` en tu navegador.
3. ¡Empieza a jugar!

## 🧠 Características
- Incluye sonidos correctos e incorrectos.
- Muestra imágenes dinámicas.
- Tiene tres pistas de música.

## 🛠️ Tecnologías utilizadas
- HTML
- CSS
- JavaScript
